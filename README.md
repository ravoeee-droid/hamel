# HAMEL Website Demo

High-end Konzept-Demo für die Volker Hamel GmbH, Romrod-Zell.

## Deploy auf Vercel

1. Repository in Vercel importieren.
2. Framework Preset: **Other** / automatisch erkennen lassen.
3. Kein Build Command nötig.
4. Deploy.

## Enthalten

- Original HAMEL-Zell Logo (freigestellte Demo-Fassung)
- bereitgestellte HAMEL-Team-/Generationenaufnahme
- bereitgestelltes HAMEL-Lkw-Foto
- GSAP + ScrollTrigger Motion
- Lenis Smooth Scroll
- cinematic Hero, Parallax, Magnetic CTAs, horizontal scroll story, SVG route animation
- interaktiver Vermarktungs-Check
- responsive/mobile + prefers-reduced-motion
- noindex Demo-Konfiguration
